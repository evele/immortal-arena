# Open Questions

This document tracks unresolved decisions.

## Seasons And Resets

- Should Immortal Arena use seasonal resets?
- How long should a season last?
- What should reset at the end of a season?
- What should survive between seasons?
- Should warriors persist but have seasonal stats reset?
- Should Fame or legacy score persist forever?
- Should some NFTs be seasonal and others permanent?
- Should each season have a random special attribute bonus like the original rounds?
- Should reaching level 100 make a warrior Immortal?
- If Immortal warriors exist, what survives with them across seasons?
- Should Immortality be prestige-only, gameplay-affecting, or both?
- How do seasons stay fair if some assets persist?

## Blockchain Ownership

- Is the lord itself an NFT, a wallet-bound profile, or an off-chain account linked to wallet?
- If wallet login is included, should lord creation happen automatically on first wallet connect?
- Are warriors fully transferable NFTs?
- If warriors are transferable, how do we prevent pay-to-win from becoming too dominant?
- Should warrior progression live on-chain, off-chain, or hybrid?
- Should battle history be committed on-chain?
- Should only important milestones be committed on-chain?
- Which low-cost/gasless chain is the best fit: EVM, Sonic, Gnosis, Starknet/Cairo, Immutable, Solana, or another option?
- How should random events be generated, verified, or committed if they interact with blockchain state?

## Economy

- Should gold be purely off-chain?
- Should gold ever be withdrawable or tradable?
- Should there be any premium currency?
- How does the game prevent bots from farming value?
- Should new players start free?
- Should warrior minting cost anything?
- Should buying additional warrior slots cost gold, crypto, both, or neither?

## Combat

- MVP uses HP, Damage, Defense, Accuracy, Agility, and Speed.
- What is the combat formula?
- How is randomness generated?
- How transparent should the battle log be?
- Can players attack anyone, or only players within a matchmaking range?
- Can a player be attacked while all warriors are wounded?
- Is defense represented by the current roster automatically?
- Should the 100-action draw limit scale with the number of warriors in battle?
- What exact damage bonus should racial hatred grant?
- What formula change can improve Goblin performance and reduce Dwarf dominance without directly changing warrior catalog stats?

## Warriors

- The MVP races are currently Human, Orc, Elf, Dwarf, and Goblin.
- The original hatred cycle should be preserved.
- Should race bonuses be fixed, randomized, or partially inherited?
- Warriors should not have random base stats at recruitment/mint.
- Can warriors be renamed?
- Can warriors be retired, burned, fused, or upgraded across seasons?
- What warrior classes/tiers exist per race?
- Which lord levels unlock each warrior class/tier?
- What happens if a player sells or transfers all warriors?

## Items

- Are items needed in the MVP?
- Should items be NFTs?
- Should items persist across seasons?
- Should item durability exist?
- Should item classes/subclasses follow the original structure?

## Daily Limits

- Should the base be exactly two attacks per day?
- How many days of attacks can stack?
- Should training sessions stack using the same rules?
- Should higher lord level increase daily attacks?
- Should increasing daily attacks become more expensive after a threshold?

## MVP Boundaries

- Is training required in the first playable version?
- Is equipment required in the first playable version?
- Is salary required in the first playable version?
- Is warrior recruitment required in the first playable version?
- Is a leaderboard required in the first playable version?
